# Punk Kid font notice

**Punk Kid Regular** is by **Chris Hansen (Christopher Hansen)**.

The current 1001 Fonts listing states that Punk Kid is free for personal and commercial use, and includes an author update from 2020 confirming free commercial use.

Source / license reference:
https://www.1001fonts.com/punk-kid-font.html

MoLife bundles `PunkKid.ttf` only for the main MoLife wordmark. The font file was imported from an existing public copy of Punk Kid because the repository connector cannot directly download binary files from 1001 Fonts.

If the title font is replaced later, remove the font asset and this notice together.
